# Message sounds

Each folder here is a sound set, named after the folder. People choose one in Settings, or "shhhhh" for none. One sound from the chosen set is picked at random each time a message arrives or is sent.

- **Formats**: `.mp3`, `.wav` or `.m4a`. All three play in every browser the app supports. Avoid `.ogg`, which older iPhones cannot play.
- **Length**: short, ideally under two seconds, with no silence at the start (the sound should begin the moment a message lands).
- **Loudness**: about the same across a set, peaking around −3 dB.
- **Size**: a set is downloaded the first time it is needed, so keep each under about half a megabyte. Mono is fine.

To add a set, add a folder; it appears in Settings after the next deploy. `snrdl` is the default and is listed first, then `plink`, then any others by name.

- `snrdl/`: the app's own sounds. Snrdle sounds by Elan Katin.
- `plink/`: three generated blips.
